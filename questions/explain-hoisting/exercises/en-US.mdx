## function-declaration-vs-expression [single-select]

### Prompt

What happens when this code runs?

```js
console.log(declared());
console.log(expressed());

function declared() {
  return 'function declaration';
}

var expressed = function () {
  return 'function expression';
};
```

### Options

- [ ] `both-log-values`: Both strings are logged successfully.
- [x] `declaration-then-type-error`: `'function declaration'` is logged, then calling `expressed` throws a `TypeError`.
- [ ] `reference-error-before-output`: A `ReferenceError` is thrown before anything is logged.

### Explanation

Function declarations are initialized with their function body before execution. The `var expressed` binding is also available, but its function assignment has not run yet, so its value is `undefined` and calling it throws a `TypeError`.
