## function-declaration-vs-expression [single-select]

### Prompt

O que acontece quando este código é executado?

```js
console.log(declared());
console.log(expressed());

function declared() {
  return 'function declaration';
}

var expressed = function () {
  return 'function expression';
};
```

### Options

- [ ] `both-log-values`: As duas strings são exibidas normalmente.
- [x] `declaration-then-type-error`: `'function declaration'` é exibido e, em seguida, chamar `expressed` lança um `TypeError`.
- [ ] `reference-error-before-output`: Um `ReferenceError` é lançado antes de qualquer saída.

### Explanation

Declarações de função são inicializadas com o corpo da função antes da execução. A associação `var expressed` também existe, mas a atribuição da função ainda não ocorreu. Portanto, seu valor é `undefined` e chamá-la lança um `TypeError`.
