Which statements about JavaScript data types are correct? Select all that apply.

## Options

### seven-primitives (correct)

The primitive types are Undefined, Null, Boolean, Number, BigInt, String, and Symbol.

> These values are not objects and form the language’s primitive categories.

### arrays-are-objects (correct)

Arrays, Dates, Maps, Sets, and regular expressions are specialized objects.

> They have distinct behaviors but belong to the Object language type.

### functions-callable-objects (correct)

Functions are callable objects even though `typeof` reports `"function"` for them.

> The special `typeof` result does not make Function a primitive type.

### null-object-type

`null` belongs to the Object type because `typeof null` is `"object"`.

> `null` is a primitive; the `typeof` result is a historical quirk.

### integer-separate-type

Ordinary integer and floating-point values are separate JavaScript language types.

> Both are Number values; BigInt is the separate arbitrary-precision integer type.
