Given `<input id="name" value="initial">`, what does this code log after it runs?

```js
const input = document.querySelector('#name');
input.value = 'edited';
console.log(input.value, input.getAttribute('value'));
```

## Options

### edited-initial (correct)

`edited initial`

> The property reflects the current live input value, while the value attribute retains the initial/default value in markup.

### edited-edited

`edited edited`

> Changing the live value property does not necessarily rewrite the corresponding content attribute.

### initial-edited

`initial edited`

> The assignment targets the property, so the live value becomes edited while the attribute stays initial.

### initial-initial

`initial initial`

> The input property assignment immediately changes the current DOM state.
