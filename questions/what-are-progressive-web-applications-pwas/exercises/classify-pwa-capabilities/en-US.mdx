Which statements about Progressive Web Applications are correct? Select all that apply.

## Options

### progressive-enhancement (correct)

A web application can progressively add installation, offline, background, or notification capabilities where the platform supports them.

> PWA describes web experiences enhanced by available platform capabilities rather than one guaranteed feature set.

### manifest-metadata (correct)

A web app manifest supplies metadata used by installation experiences, such as names, icons, and display behavior.

> The manifest describes how the installed web application should be presented.

### service-worker-common (correct)

A service worker commonly implements offline routing, cache strategies, and push/background behavior.

> It can respond to network-related events independently of the currently open page.

### secure-context (correct)

Powerful PWA capabilities generally require a secure context.

> HTTPS protects the integrity of code that can persist and act with elevated browser capabilities.

### identical-install-rules

Every browser and operating system exposes identical installation criteria and capabilities.

> Support, UI, requirements, and feature availability vary by browser and platform.
