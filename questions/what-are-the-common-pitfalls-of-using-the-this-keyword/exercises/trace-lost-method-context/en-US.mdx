What does this strict-mode code log?

```js
'use strict';

const user = {
  name: 'Ada',
  read() {
    return this?.name;
  },
};

const callback = user.read;
console.log(user.read(), callback());
```

## Options

### ada-undefined (correct)

`Ada undefined`

> The method call supplies `user` as the receiver, while the detached plain call has `this === undefined` in strict mode.

### ada-ada

`Ada Ada`

> Retrieving a method does not permanently bind it to the source object.

### undefined-ada

`undefined Ada`

> The object property call has the receiver; the detached call does not.

### throws

It logs `Ada`, then throws.

> Optional chaining on the undefined receiver returns `undefined` instead of throwing.
