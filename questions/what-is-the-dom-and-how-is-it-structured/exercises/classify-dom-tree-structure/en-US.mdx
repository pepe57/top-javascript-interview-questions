Which statements about the Document Object Model are correct? Select all that apply.

## Options

### programming-interface (correct)

The DOM is a programming interface representing a document as objects that code can inspect and modify.

> It exposes structure, content, and related behaviors to scripts and tools.

### tree-nodes (correct)

A document is organized as a tree containing node types such as Document, Element, and Text nodes.

> Parent/child and sibling relationships describe document structure.

### html-source-can-differ (correct)

The live DOM can differ from the original HTML source after parser correction or script mutations.

> The DOM is the current parsed object model, not merely the source string.

### css-only

The DOM contains only computed CSS styles and no content nodes.

> Styles are related through separate CSSOM/computed-style APIs; the DOM includes document nodes and content.

### plain-html-string

The DOM is just one immutable HTML string that cannot be changed after parsing.

> DOM APIs can add, remove, replace, and modify nodes during the document’s lifetime.
