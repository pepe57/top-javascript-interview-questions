What does this non-strict code log?

```js
const object = { count: 1, removable: true };
Object.preventExtensions(object);
object.count = 2;
object.extra = 3;
delete object.removable;

console.log(object.count, object.extra, 'removable' in object);
```

## Options

### two-undefined-false (correct)

`2 undefined false`

> Preventing extensions blocks new properties, but existing writable properties can change and configurable properties can be deleted.

### one-undefined-true

`1 undefined true`

> The operation does not make existing properties non-writable or non-configurable.

### two-three-false

`2 3 false`

> The non-extensible object cannot receive the new `extra` property.

### one-three-true

`1 3 true`

> This reverses all three effects: existing properties remain mutable/deletable, but additions fail.
