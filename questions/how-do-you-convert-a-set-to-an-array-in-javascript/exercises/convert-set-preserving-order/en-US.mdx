What does this code log?

```js
const values = new Set([3, 1, 3, 2]);
const array = [...values];
console.log(array.join(','));
```

## Options

### three-one-two (correct)

`3,1,2`

> A Set keeps unique values in insertion order, and spread iterates them into the new array.

### one-two-three

`1,2,3`

> Converting a Set does not sort its values automatically.

### three-one-three-two

`3,1,3,2`

> The duplicate `3` was removed when the Set was constructed.

### set-string

`[object Set]`

> Spread consumes the Set iterator rather than coercing the Set to a string.
