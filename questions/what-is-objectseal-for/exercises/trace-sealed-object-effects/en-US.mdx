What does this non-strict code log?

```js
const object = { count: 1 };
Object.seal(object);
object.count = 2;
object.extra = 3;
delete object.count;

console.log(object.count, object.extra, Object.isSealed(object));
```

## Options

### two-undefined-true (correct)

`2 undefined true`

> Sealing keeps the existing writable value mutable, blocks new properties, and makes the existing property non-configurable so deletion fails.

### one-undefined-true

`1 undefined true`

> Unlike freezing, sealing does not make a writable data property non-writable.

### two-three-true

`2 3 true`

> A sealed object is non-extensible and cannot receive `extra`.

### undefined-undefined-true

`undefined undefined true`

> The existing property becomes non-configurable and cannot be deleted.
