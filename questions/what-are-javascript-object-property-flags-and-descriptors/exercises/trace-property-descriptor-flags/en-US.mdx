What does this non-strict code log?

```js
const object = {};
Object.defineProperty(object, 'token', {
  value: 'A',
  writable: false,
  enumerable: false,
  configurable: false,
});

object.token = 'B';
delete object.token;
console.log(object.token, Object.keys(object).length);
```

## Options

### a-zero (correct)

`A 0`

> The non-writable assignment and non-configurable deletion fail, while the non-enumerable property is absent from `Object.keys()`.

### b-zero

`B 0`

> The descriptor prevents changing the data property’s value.

### undefined-zero

`undefined 0`

> A non-configurable property cannot be deleted.

### a-one

`A 1`

> `Object.keys()` includes only enumerable own string properties.
