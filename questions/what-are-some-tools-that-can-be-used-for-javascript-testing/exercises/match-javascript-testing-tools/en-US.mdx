## Options

### jest-vitest-runner (correct)

Jest and Vitest are batteries-included choices for JavaScript unit and integration tests.

> They combine a runner with assertions, mocking, and common test conveniences.

### node-test-runner (correct)

Node.js includes a built-in `node:test` runner.

> Server-side projects can test without adopting a third-party runner.

### playwright-cypress-browser (correct)

Playwright and Cypress automate browsers for end-to-end or component testing.

> They operate at a different layer from a typical pure-unit runner.

### testing-library-complements (correct)

Testing Library provides user-focused query and interaction helpers that complement a test runner.

> It does not replace execution, assertion, and environment orchestration by itself.

### one-best-tool

> Framework integration, browser needs, runtime, isolation, and CI constraints should drive the stack.
